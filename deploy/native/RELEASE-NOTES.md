Tupi Battle Grounds native Linux preview with the shared Bevy interface.

- Practice offline, or play on the same authoritative server as browser players.
- Account login, lobby, private rooms/challenges, Arcanas, Strongholds, Arenas,
  live-match watching, Ranking, Shop, Evolution, Fortification and War Council.
- Native TLS/audio, private local preferences, keyboard text entry, clipboard,
  fullscreen, VSync/shadow controls and a per-user Linux installer.
- Portable `.tar.gz` and AppImage, each with a SHA-256 checksum. Extract the
  tar.gz and run `./install.sh` for a menu launcher, or run `./tbg-client`.
- `build-info.json` records the version, source commit and executable digest.

Windows follows after the Linux artifact is validated and installed. The
public HTML `/ranking/` page remains available. The bundled TBG Visible Attribution License permits commercial reuse with
persistent on-screen creator/profile/repository credit; third-party materials
retain their own notices. Hardware and visual acceptance evidence is tracked in
`docs/phases/NATIVE-client.md` at this release's source revision.
