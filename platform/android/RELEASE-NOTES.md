# Tupi Battle Grounds — Android beta (0.1.4-colossus.7-android.56)

Native landscape Android with the current shared Linux game: full-window
scenery, measured safe touch controls, compact menus and battle HUD, native
forms, Practice and Training, current champions (including the Blender champion
meshes now on main), Evolution, Fortification, War Auxiliaries, War Council and
complete match results. The Blender arena, Stronghold and War Auxiliary studies
are not yet runtime assets on any platform; the arenas and towers shown are the
existing procedural ones.

Install the ARM64 APK on Android 12/API 31 or newer. It uses the same package
and signing certificate as the reviewed prototype, so a normal in-place
upgrade keeps its nonsecret preferences. Keep your explicit account-key backup.
The app does not store account credentials between process restarts.

This is an early beta. Emulator runtime is verified; installing the earlier
prototype on an ARM64 phone did not constitute physical gameplay or 16 KB runtime
acceptance. Physical audio, thermal behavior and the full device matrix remain
pending. No universal Android or store-readiness claim is made.

The public APK is a non-debuggable release build, uses the official WSS service
and contains no internal loopback feature. Online play requires its exact
MatchContract on the official server. The website enables downloads through
the same verified compatibility gate as Linux and Windows. If the service is
still on an earlier protocol, online admission remains unavailable; local
Practice and Training can be used while the service upgrade is pending.

APK, inspection report, SHA-256 sidecars and GitHub hosted-builder provenance
are published together without replacing an existing release asset.
