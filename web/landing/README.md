# Landing (`tupibg.com`)

Static, responsive (desktop and phone) landing page: header, hero, the game's pillars, how a match plays, champions by
Faction, the eight Arenas, real captures, patch notes, platforms and footer, plus draft
contact/privacy/terms pages and a 404 page.

## Layout

| Path | Responsibility |
|------|----------------|
| `index.html`, `contact/`, `privacy/`, `terms/`, `404.html` | Pages; pt-BR text is authored in the HTML |
| `assets/css/landing.css` | Layout and sections (tokens/base come from `web/shared`) |
| `assets/js/main.js`, `page.js` | Entry points (home page; secondary pages) |
| `assets/js/nav.js` | Compact-screen section menu, scrolled header state and section reveal (the page works without it) |
| `assets/js/i18n.js` + `assets/i18n/{pt-BR,en}.json` | Language switch for `[data-i18n]` text and `[data-i18n-attr]` attributes |
| `assets/js/release.js` + `config/release.json` | Availability gates for the browser game and the Linux package |
| `assets/js/champions.js`, `arenas.js`, `news.js`, `gallery.js` | Data-driven sections and the screenshot viewer |
| `data/champions.json`, `data/arenas.json` | Generated by `web/scripts/sync_content.py`; never edit by hand |
| `media/` | Optimized derivatives: wordmark, hero art, native captures, social image |
| `site.manifest` | Repository files published as-is (fonts, portraits, Arena previews, icons, patch catalog) |

## Language

The HTML holds pt-BR so the page reads without JavaScript; `pt-BR.json` must repeat that text
exactly and `en.json` must have the same keys (`check.py` enforces both). Choice order:
`?lang=`, saved preference, browser language. Keep `data-i18n` on leaf text elements.

## Availability gates (`config/release.json`)

- `webGame.state`: `pending` (default) keeps "Jogar no navegador" inactive with "Em breve".
  Set `live` only after `https://app.tupibg.com/` serves the published, verified web build.
- `linux.state`: `pending` (default) shows "Em preparação". `available` requires `version`,
  `protocol`/`contract` equal to `server` (and to tbg-core: `check.py` reads
  `PROTOCOL_VERSION`, `RULESET_VERSION` and the ruleset registry), and GitHub release assets
  with `kind` (`appimage`|`tarball`), exact URL, `sha256` and `bytes`. On 2026-11-01 the
  newest published package, `v0.1.1-rc.1`, is protocol 30 (`w30-r2-3d56156049e626c5`) and the
  server is protocol 31 (`w31-r6-097385fee9a10b0f`), so no download is offered.
- Windows uses the same verified catalog for its installer and portable ZIP.
- Android beta uses a separately versioned, source-bound ARM64 APK, a pinned
  signing certificate and the same live compatibility gate. It requires Android
  12/API 31 or newer. The static fallback for all three systems remains pending;
  only the server-side verified catalog can enable downloads.

The browser repeats the same validation, so a malformed file stays in the safe pending state.

## Content sources

- Champions, Factions, Archetypes and Arena effects: `web/scripts/sync_content.py` (tbg-core
  `COMPLETION_POOL` (81 authored kinds), `FULL_POOL` availability and content table, client i18n names, client Arena data). Portraits and Arena
  previews are the client's own renders.
- Patch notes: `docs/patches/catalog.json` copied at staging; the page shows title, summary,
  date, version and status only (technical sections stay in the game and repository).
- Captures: the current gallery and root README share real native Linux
  release-profile `0.1.4-colossus.5` Practice screenshots. Forest and Tundra
  matches include War Auxiliaries, Augments, inspection panels and the result
  of a complete match. See [capture provenance](../../docs/evidence/readme-linux-release.md)
  for the exact CI package, hashes, method and acceptance limits. Derivatives
  are 1280 × 720 with 800 × 450 thumbnails; no content was painted over.
- Hero/social background: real Linux Forest release capture; wordmark:
  `lobby/wordmark.webp` (owner-selected wordmark for the lobby brand); emblem: branding.

The 2026-11-03 update uses the README's real release captures for the hero and
gallery, with a real Forest frame for the social image/background. Three
additional native Android emulator captures show battle, Council and the
Colossus B2 catalog. All 84 portraits and eight Arena previews keep their canonical
client files with content-hash URLs, so updated assets do not reuse stale cache
entries. See [media provenance](../../docs/evidence/landing-android-beta-20261103.md).
