# Ranking artwork

Six original raster illustrations generated with the native image generation tool on 2026-10-30. The owner-provided ranking image guided layout only; no pixels were copied. Bronze/iron, parchment, red/blue/green cloth and painterly medieval materials follow the Arcana and Augment art direction.

The first five images preserve transparency. Podiums have blank nameplates and medallions; names, ranks, Rating and W/L/D remain accessible DOM text. No lettering, numbers or fake records are baked into art.

`python scripts/ranking_art.py` reuses existing normalization and alpha-weighted fidelity measurement. WebP uses Q90 at 2x display size; the trophy and crest use lossless encoding at 4x to preserve fine edges. No new dependency. Painterly images remain raster instead of large vector traces. Originals remain in the generation cache and private `.local/art-masters/ranking/`; masters and build outputs are not committed.

Total: **1,652,084 bytes**, below the **2,000,000-byte** technical budget. All pass display SSIM >= 0.97 and alpha MAE <= 1. The trophy initially measured 0.969782 at 2x; 4x lossless sampling raised SSIM to 0.979089. No gate was lowered.

Measured tool versions: Pillow 12.2.0, numpy 2.4.6, scipy 1.18.0.
