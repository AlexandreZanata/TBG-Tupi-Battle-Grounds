# Shared desktop and protected delivery candidate

Version: 0.1.1-rc.1+delivery. Candidate, not a promoted complete release.
Protocol 31; schema 10; ruleset 6 / `097385fee9a10b0f`.

The browser uses the same Bevy desktop presentation as Linux, retaining the roster,
training library, illustrated Shop/Augments, common header and loading refinements.
The consolidation preserves the integrated gameplay values and does not claim new
D-33 acceptance. See the earlier P71 preview for its Proposed values and limits.

Independent main-CI-approved artifact families cover compatible server, browser and
public static updates. Immutable browser asset URLs preserve open tabs. Frontend
updates do not restart the game or reload the proxy; backend updates drain before
replacement without force-killing matches or restoring old player data. Provenance,
source ancestry and exact contract/schema checks gate automatic activation.

The landing and script-free public admin preparation page are included. The fictional
admin console is local-only; privileged actions, email delivery, native signing
custody and real Windows visual acceptance are not completed by this update. Mobile
is outside scope. Host controllers remain disabled until a real main artifact is
verified and its first delivery observed.

Actual commands, operations and deferred acceptance are recorded in the
[consolidation report](../phases/PLAYER-safe-consolidation.md). Follow
[RELEASES](../RELEASES.md) before enabling any release family.
