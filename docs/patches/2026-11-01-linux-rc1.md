# Consolidated Linux candidate: recoverable updates with protected sign-in

Version: 0.1.1-rc.1. Status: prerelease candidate. Protocol: 30. Schema: 10.
Ruleset: 2 / 3d56156049e626c5. Gameplay and balance numbers are preserved.

This candidate joins the work of the open pull requests #18-#33 in one build:
the complete 46-champion roster and its forms, the five refined arenas with
training in every arena, the training laboratory, the victory celebration,
English/pt-BR presentation, ranked records, the competitive audit and
illustrated patch notes, protected sign-in (P68) and the recoverable Linux
updater foundation (P66).

Sign-in and match resume now share one coordinator. Access stays in memory;
optional "Keep me signed in" uses the real Linux Secret Service, which also
holds the short-lived resume record that lets a restarted client return to
its original server generation. A locked or unavailable vault shows a visible
temporary session after at most five seconds, never a plaintext fallback.
Updates wait while sign-in, renewal, restore, queueing, a match or a
reconnect is in progress.

The competitive audit did not approve new balance values: its recorded
failures remain open and no number changed. The protocol-29 production server
is not compatible with this candidate; offline Practice and the training
laboratory work without it. Official signing and automatic updates (owner
gate O02), Windows and two-slot server rollout remain inactive.

See the [consolidation report](../phases/CONSOLIDATION-20261101.md) for the
merged pull requests, resolved conflicts, executed checks and open gates.
